Начнем наш урок

Ты узнаешь как называть животных на французском языке.

Домашние: le chat (кот), le chien (собака), le lapin (кролик), le poisson (рыбка).

Дикие: le lion, le tigre, lel elephant, la girafe, le singe, lours.

Фразы: Jaime les chats (мне нравятся коты), Je n aime pas les serpents (не люблю змей).

Выключи микрофон и прочитай текст вслух взрослым  
Au zoo, jai vu un elephant, une girafe et des lions. Jaime beaucoup les singes. Ils sont amusants! Mais je n aime pas les serpents. Ils sont effrayants.

Этот текст описывает поход в зоопарк.

Правило: перед существительным стоит артикль: le (м.р.), la (ж.р.), les (мн.ч.).

А ты знаешь, что в Париже есть знаменитый зоопарк в парке Венсен?

Интересный факт: слово chat (кот) дало название программе для общения — chat, потому что коты «болтают».

Проверь себя: опиши двух животных, которые тебе нравятся, и одно — которое не нравится.

Профессии, где это важно: ветеринар, зоолог, фотограф. Все они работают с животными.

Запомни: животные — универсальный язык доброты.
